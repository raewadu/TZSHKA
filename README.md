# Kanban Board

Веб-приложение для управления задачами с канбан-доской, drag & drop и фильтрацией.

Пользователь может создавать доски, добавлять задачи, перемещать их между колонками, редактировать и фильтровать задачи.

## 🚀 Функционал

- Регистрация и авторизация пользователей
- Создание и удаление досок
- Создание задач
- Drag & Drop задач между колонками
- Удаление задач через корзину
- Редактирование задач через модальное окно
- Изменение:
  - названия
  - описания
  - приоритета
  - тегов
- Поиск и фильтрация задач:
  - по названию
  - по автору
  - по приоритету
  - по тегам
- Темная и светлая тема
- Страница профиля
